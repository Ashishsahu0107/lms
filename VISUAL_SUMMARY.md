## 💡 QUICK TIPS

### To Customize Colors
→ Edit `frontend/tailwind.config.js`

### To Add New Page
→ Create in `frontend/src/pages/NewPage.jsx`
→ Add route in `frontend/src/App.jsx`

### To Add New Component
→ Create in `frontend/src/components/NewComponent.jsx`
→ Import and use where needed

### To Connect Backend (Later)
→ Update `VITE_API_URL` in `.env`
→ Build backend following COMPLETE_SETUP.md
